# University Portal V2
**Студентка:** Владислава Троянова

## Опис проєкту
Система керування університетом на Java з використанням динамічного виділення пам'яті та модульного консольного інтерфейсу.

## Технічні деталі (Екземпляр 2)
- **Зберігання даних:** Динамічні масиви (розширення через `Arrays.copyOf()`).
- **Ідентифікатори:** Автоінкрементні цілі числа (int).
- **Інтерфейс:** Модульне консольне меню для зручної навігації.
- **Структура:** Повна відповідність вимогам ООП, використання enum та інтерфейсів.

## Запуск
Головний клас для запуску програми: `Main.java`. Реалізовані всі CRUD-операції, а також система розрахунку GPA.
